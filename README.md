# A9 Telemetry Lab

基于 Stitch 原型重构的“狂野飙车 9”视频性能分析网页。视频帧与分析数据均留在浏览器本地；首次使用 OCR 时会下载英文数字识别模型。

## 功能

- 拖放或选择本地 MP4/WebM，播放、定位、逐帧审核；Edge 与 Chrome 均已验证
- 分别拖动、缩放速度表和局内计时器的 ROI 框，带放大预览和右上区域自动定位
- 手动录入或修正的数据会锁定为真值，不被自动识别、时间修复或速度修复覆盖，并作为相邻帧参考
- 自动检测视频帧率，支持整段或指定区间按“每 N 帧”采样
- 计时器使用多预处理 OCR 投票与置信度加权的稳定偏移簇；结合手动锚点独立修正异常时间，避免单帧错误向后传播
- 播放器支持上一帧、下一帧按钮及左右方向键逐帧审核
- 使用五点滑动中位数和两侧趋势识别孤立速度突变，插值修正并保留原始速度
- 对三路预处理 OCR 结果进行多数投票，并结合前后速度趋势专门修正 `5`/`9` 混淆
- 使用局内计时器数据（而非视频时间）绘制 v-t 曲线，数据点支持显示/隐藏和交互提示
- 导出名称可修改的 UTF-8 CSV 或 XLSX
- 导入多份 CSV/XLSX，裁剪片段并按原始时间或片段起点归零进行对比
- 对比图支持导出 2 倍分辨率 PNG 或可编辑 SVG
- 对比图可导出 1280×720 动态 MP4：曲线随时间显现，当前节点和具体速度实时高亮，支持 0.5×–8× 播放倍率
- 桌面、平板和手机响应式布局；移动端速度采用轻量识别，计时保持高精度投票，并带帧率检测与暂停跳帧解码兜底

## 本地运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
npm run preview
```

## 使用建议

1. 载入视频后，把绿色框对准速度数字，把蓝色框对准局内计时器。
2. 先暂停在数字清晰的画面，点击“识别当前帧”验证框选是否准确。
3. OCR 会受到动态模糊、光效和 UI 皮肤影响；自动扫描后应抽查低置信度记录。
4. Edge/Chrome 无法直接解码 HEVC 时，网站会在浏览器本地进行兼容转换；H.264 MP4 可直接使用。

## 项目结构

- `src/components`：视频、采集、数据日志与图表组件
- `src/lib/capture.ts`：视频区域截取与 OCR
- `src/lib/time.ts`：局内时间解析
- `src/lib/export.ts`：CSV/XLSX 导出
- `src/types.ts`：共享数据模型
- `speed-dataset`：从测试视频提取的速度表专用数字训练集与数据卡
